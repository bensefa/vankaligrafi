# VanKaligrafi

**Dijital kaligrafi çalışma ve kişiselleştirilmiş yazı platformu**

🌐 **Canlı proje:** https://vankaligrafi.com/

VanKaligrafi; kullanıcıların farklı kaligrafi yazı tipleriyle metin oluşturabildiği, çalışma sayfalarını düzenleyebildiği ve üyelik sistemi üzerinden kişisel araçlara erişebildiği modern bir web uygulamasıdır.

> Bu repository bir **proje vitrini / portföy sayfasıdır**. Canlı sistemin kaynak kodları ve hassas yapılandırmaları yayımlanmamaktadır.

## Projede geliştirilen başlıca özellikler

- E-posta ve şifre ile üyelik/giriş sistemi
- Kullanıcı hesabı ve kişisel kontrol alanı
- Kaligrafi metni oluşturma ve canlı önizleme
- Çoklu kaligrafi font desteği
- Görsel font seçici
- Admin panelinden font ekleme ve yönetme
- Fontları aktif/pasif yapma ve kaldırma
- A4 çalışma sayfası düzeni
- Karakter sınırı ve içerik kontrolleri
- Logo ve site ayarlarının admin panelinden yönetimi
- Masaüstü ve mobil uyumlu arayüz
- Tutarlı header ve kullanıcı paneli tasarımı

## Teknolojiler

**Backend:** PHP, MySQL  
**Frontend:** HTML5, CSS3, JavaScript  
**UI/UX:** Responsive Web Design  
**Yönetim:** Özel admin ve kullanıcı paneli

## Güvenlik

Bu repository kaynak kod deposu değildir. Veritabanı erişimleri, kullanıcı bilgileri, şifreler, API anahtarları ve sunucu yapılandırmaları yayımlanmaz.
